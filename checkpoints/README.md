# Checkpoints Directory

This directory stores the pre-trained original base models used for the unlearning experiments:

- `cifar10_trained_original.keras`
- `cifar100_trained_original.keras`
- `imagewoof_trained_original.keras`

## Purpose

These models are trained on the complete dataset before any unlearning method is applied.

## Version Control

Base model files are ignored in Git (except for this README) due to their large file size.
